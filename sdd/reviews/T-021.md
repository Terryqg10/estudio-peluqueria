## Datos y privacidad

Toca datos personales. Enmienda de la sección 9 de la spec (ADR-0034): la cita de cuenta guarda copia de nombre, email
y teléfono (como una invitada) y el perfil guarda nombre y teléfono. El borrado y la retención (T-012) ya los cubren;
el borrado por email de invitada (T-020) no toca estas citas (solo las de `user_id` nulo).

## Problemas conocidos

- **Copia de contacto duplicada** en cada cita de cuenta: si la clienta cambia de nombre o teléfono, las citas
  antiguas conservan el valor con el que se reservaron (como las de invitada). Aún no se puede editar el perfil.
- **No se vuelve a `/reservar` tras entrar** con el enlace mágico (va a «Mis citas»); no hay enlace «Entrar para
  reservar con tu cuenta» en el formulario (fuera de alcance).
- **Cancelar o cambiar desde «Mis citas»** sigue sin existir: se hace con el enlace del email de la cita.
- **T-018** sigue pendiente: el Admin mueve o cancela y la clienta no recibe aviso.
- La base de datos local conserva filas de servicios de prueba de otros tests (se ven en la captura); no es de esta tarea.
- Fragilidad de tiempo real (T-014): ver «Incidencias durante la verificación».
- No se hizo la comprobación de mutación (romper el código y ver fallar los tests).
- Se abrió Docker Desktop de nuevo (se había cerrado) para aplicar la migración y ejecutar las pruebas.
