# Checklists de bloques por tipo de página

Lista de referencia que usa `/auditar-pagina`. Cada bloque debe existir (o
estar justificado su descarte en `## Decisiones de UI` del plan), usar solo
tokens, ser responsive de 320 a 1280 px y cumplir WCAG AA.

## Home

- TopBar
- Header sticky
- Hero
- Categorías
- Banner
- Novedades (carrusel)
- Newsletter
- App
- Footer

## Catálogo (PLP)

- Cabecera
- Barra de orden
- Filtros (acordeón)
- Grid de productos (hover y tallas)

## Ficha de producto (PDP)

- Galería
- Precio
- Colores
- Tallas
- Añadir al carrito
- Acordeón de información
- Relacionados

## Carrito

- Lista de productos
- Cupón
- Cross-selling
- Resumen
- Pagos
- CTA

## Servicios (ej. peluquería)

- Hero
- Precios
- Fecha (7 días)
- Hora (píldoras)
- Formulario
- Resumen sticky

## Dashboard

- Sidebar
- Topbar

- Paginación
